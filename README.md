# sunrise-poster

在日出的那一刻自動發一則 Threads 貼文。週末與國定假日休息。

## 為什麼不是普通的排程

日出時間每天都在變（台北全年 05:03～06:40），cron 只能設固定時間；
而 GitHub 的 `schedule` 會排隊，實測延遲數十分鐘到數小時。

解法是**不要讓觸發端負責準時**：外部 cron 每天在固定時間叫醒 job，
job 起來後自己算出當天日出的時分秒，把準備工作全做完，
再睡到日出前十幾秒醒來發文。觸發端晚多久都不影響發文時間。

實測睡眠誤差 15 毫秒，最終精準度只受 API 網路延遲影響。

## 放假規則

「週休二日 + 見紅就休」不能自己算——台灣有補假和補班日。
所以直接查政府的行政機關辦公日曆表，它怎麼說就怎麼算。
查不到時退回「只休週六日」，免得整個停擺。

## 設定

貼文內容由 `POST_CHARS` / `POST_LENGTH` / `POST_SUFFIX` 決定，
不寫在程式裡。詳細設定步驟見 [docs/SETUP.md](docs/SETUP.md)。
